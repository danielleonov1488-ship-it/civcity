# Steal a Legion — прототип для Roblox

Римская версия самой популярной сейчас формулы Roblox «Steal a …» (Steal a Brainrot, Steal An Egg).

## Как играется

- **База.** У каждого игрока своя база с постаментами: 8 в начале, +2 за каждое перерождение, максимум 16.
- **Покупка.** По Священной дороге (Via Sacra) из триумфальной арки идут римляне разной редкости, от крестьянина за $25 до Юпитера за $250M. Подходишь, жмёшь E — и купленный юнит сам идёт к тебе на базу.
- **Доход.** Каждый римлянин на постаменте приносит деньги каждую секунду. Они копятся на зелёной плите перед постаментом, встал на плиту — забрал.
- **Кража.** На чужой базе держишь E 1,2 секунды над чужим римлянином, он оказывается у тебя над головой, и ты бежишь к себе медленнее обычного. Донёс до своей базы — он твой.
- **Защита.** Хозяин (или любой игрок) бьёт вора гладиусом (клик мышью). Вор отлетает, а добыча возвращается домой.
- **Замок.** Красная плита у ворот запирает базу на 60 секунд (+10 за перерождение): в воротах встаёт лазерная стена, через которую проходит только хозяин. При входе в игру база заперта сама на 30 секунд.
- **Перерождение.** Набрал $1M (потом $10M, $100M …) — начинаешь заново с ×1,5 к доходу за каждое перерождение и с бо́льшим числом постаментов.
- **Редкости:** обычный, редкий, эпический, легендарный (гарантированно раз в 5 минут), мифический (раз в 15 минут), божественный, секретный.
- **Мутации:** золотой (×2 к доходу) и алмазный (×3).
- **Таблица игроков:** деньги, перерождения, кражи.
- **Язык.** Русский — если в Roblox стоит русский язык, иначе английский.
- **Сохранение.** Работает в опубликованной игре; в Studio — только если включить Game Settings → Security → Enable Studio Access to API Services.

## Как открыть

Двойной щелчок по **«Open in Roblox Studio.bat»**: он собирает место из кода и открывает его в Studio. Затем нажмите Play (▶).

Чтобы проверить кражу вдвоём:
1. Вкладка Test → Clients and Servers → 2 игрока → Start.
2. Откроются два окна игроков, ими можно красть друг у друга.

## Как устроено

Код лежит обычными файлами в `src/`; `python -I build.py` собирает из них `build/StealALegion.rbxlx`.

| Файл | Что внутри |
|---|---|
| `src/ReplicatedStorage/Config.luau` | все числа: юниты, редкости, цены, доход, таймеры, перерождения |
| `src/ReplicatedStorage/Locale.luau` | тексты на русском и английском |
| `src/ServerScriptService/World.luau` | карта строится кодом: дорога, арка, 8 баз, кипарисы, свет |
| `src/ServerScriptService/Figures.luau` | фигурки римлян из деталей (слон, Минотавр, Циклоп, Цербер, Юпитер…) |
| `src/ServerScriptService/Main.server.luau` | вся логика: дорога, покупка, доход, кража, удар, замок, перерождение, сохранение |
| `src/StarterPlayer/StarterPlayerScripts/Hud.client.luau` | интерфейс: деньги, замок, перерождение, сообщения, таблички |

Моделей Synty пока нет: фигурки собраны из деталей Roblox. Модели Synty можно подключить позже — лицензия разрешает, если оставить их закрытыми (не выкладывать в Creator Store).

# Рекламный ролик CivCity

Готовые ролики в `promo/video/out/`:
- `civcity-promo.mp4` — большой ролик, 1920×1080, 75 с;
- `civcity-tiktok.mp4` — быстрый вертикальный, 40 с, под трек Thunder;
- `civcity-cozy.mp4` — спокойный вертикальный, 41 с, под своё фортепиано игры (promo/cozy-music.js).

Рендер Remotion рисует кадры на видеокарте (`--gl=angle`). Запись из игры кодирует видеокарта (NVENC), если драйвер NVIDIA версии 610 или новее; со старым драйвером — процессор.

## Как он собран

1. **Город для съёмок** — игра с адресом `#promo` (js/promo.js): большой город с кривыми улицами по кольцам и лучам, форум, Колизей, сады, рощи. Состояние хранится отдельно (`civcity.save.promo`), обычные сохранения не трогает.
2. **Съёмка** — `promo/shots.js` описывает пролёты камеры (ключи: точка взгляда, расстояние, поворот, наклон, время суток). Запись идёт через Electron на видеокарте:
   ```
   python -I promo/capture.py 5192          # приёмник кадров → ffmpeg → promo/shots/*.mp4 (2560×1440)
   cd desktop && npx electron ../promo/rec.js [клипы...] [--vertical | --cozy]
   ```
   Игра должна быть открыта локальным сервером на порту 5180.
3. **Монтаж** — Remotion в `promo/video` (титры, логотип, музыка, звуки):
   ```
   cd promo/video
   npm run studio    # посмотреть и поправить
   npm run render    # собрать out/civcity-promo.mp4
   ```
   Клипы для монтажа лежат в `public/shots` (1920×1080), звуки — в `public/audio` (синтез игры, без чужих лицензий). Эти файлы большие и в git не попадают.

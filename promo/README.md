## v2 — новая графика (Godot, витрина `--promo`)

Готовые ролики в `promo/video/out/`:

- `civcity-vertical-2.mp4` — 1080×1920, ~42 с, те же сцены, снятые отдельно под вертикальный кадр.

Музыка — наша классика из игры: Григ, «Утро» (`godot/assets/music/11_grieg_morning_mood.ogg`, запись Musopen Symphony, общественное достояние; см. CREDITS.txt там же). Широкий ролик идёт с начала пьесы до её естественного затихания на 77,4 с, вертикальный — с 35,25 с (нарастание и кульминация).

1. **Съёмка** — `godot/scripts/promo_cam.gd` (сцена `godot/promo_cam.tscn`): камера летит по сплайну по ключам клипа (точка, поворот, наклон, масштаб, час суток), кадры идут прямо в ffmpeg; экран загрузки в видео не попадает, время кадра фиксированное. Перед съёмкой город «живёт» в 11 часов (горожане выходят по делам), потом ставится свет клипа. Особые сцены: повозка с переселенцами у арки, дом под снос и рост этажей, кошка и ребёнок, который её гладит.
   ```
   bash promo/render_v2.sh              # все клипы (широкие, вертикальные, петли) и 12 снимков; по одному через замок видеокарты
   bash promo/render_v2.sh clip market  # один клип; ... clip market vertical — вертикальный
   ```
   Проверка композиции без видео: `bash .work/py/gpu_run.sh --fixed-fps 30 res://promo_cam.tscn -- check=market,cat [vertical]` → `.work/promo/cam_check`.
2. **Монтаж** — `promo/video/src/Promo2.tsx` (композиции `Promo2` и `Vertical2`, общий файл `public2`: клипы `shots2`, музыка, логотип, шрифты игры Philosopher и Alegreya Sans):
   ```
   bash promo/build_v2.sh               # оба ролика + медиа для сайта
   ```
3. **Для сайта** — `python -I promo/site_media.py` кладёт в `site_media/`: 8 бесшовных петель 1280×720 без текста (webm VP9 + mp4 H.264 + постер), 12 снимков (PNG 3840×2160, JPG 2560×1440, превью 960×540), ролик 1080p с постером и `manifest.json` с подписями.

## v1 — старая браузерная графика

Готовые ролики в `promo/video/out/`:
- `civcity-promo.mp4` — большой ролик, 1920×1080, 75 с;
- `civcity-tiktok.mp4` — быстрый вертикальный, 40 с, под трек Thunder;
- `civcity-cozy.mp4` — спокойный вертикальный, 41 с, под своё фортепиано игры (promo/cozy-music.js).

Рендер Remotion рисует кадры на видеокарте (`--gl=angle`). Запись из игры кодирует видеокарта (NVENC), если драйвер NVIDIA версии 610 или новее; со старым драйвером — процессор.

## Как он собран

1. **Город для съёмок** — игра с адресом `#promo` (js/promo.js): большой город с кривыми улицами по кольцам и лучам, форум, Колизей, сады, рощи. Состояние хранится отдельно (`civcity.save.promo`), обычные сохранения не трогает.
2. **Съёмка** — `promo/shots.js` описывает пролёты камеры (ключи: точка взгляда, расстояние, поворот, наклон, время суток). Запись идёт через Electron на видеокарте:
   ```
   python -I promo/capture.py 5192          # приёмник кадров → ffmpeg → promo/shots/*.mp4 (2560×1440)
   cd desktop && npx electron ../promo/rec.js [клипы...] [--vertical | --cozy]
   ```
   Игра должна быть открыта локальным сервером на порту 5180.
3. **Монтаж** — Remotion в `promo/video` (титры, логотип, музыка, звуки):
   ```
   cd promo/video
   npm run studio    # посмотреть и поправить
   npm run render    # собрать out/civcity-promo.mp4
   ```
   Клипы для монтажа лежат в `public/shots` (1920×1080), звуки — в `public/audio` (синтез игры, без чужих лицензий). Эти файлы большие и в git не попадают.

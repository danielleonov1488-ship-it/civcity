# Задания для Cowork: новые 3D-модели для CivCity

Ты работаешь в папке `D:\CivCity\cowork`. Здесь лежат задания на новые 3D-модели для игры CivCity — уютного
градостроителя про Древний Рим. Модели делаются в Higgsfield (подключение Higgsfield) на **бесплатном безлимите**.
Готовые файлы потом заберёт Claude Code: он доведёт их в Blender и вставит в игру.

Владелец просит: «сделай все из заданий в папке». Делай задания по порядку номеров. После каждой генерации записывай
результат в `RESULTS.md`, чтобы при обрыве ничего не потерялось.

## Главные правила

1. **Только бесплатно.** Тратить разрешено только безлимит (free-trial unlimited). Платные кредиты не тратить.
   - Если инструмент вернул вопрос `unlim_choice`, повтори вызов с `use_unlim: true`.
   - Если у модели безлимита нет и генерация спишет кредиты, **не запускай её**. Запиши в `RESULTS.md`:
     «нужны кредиты: <модель>, <сколько>». Потом переходи к тому, что можно сделать бесплатно.
2. **Сначала проверь безлимит.** Вызови `models_explore` с `action: "list"` и `unlim: true`. Запиши в `RESULTS.md`,
   какие модели картинок и какие 3D-модели доступны на безлимите и до какого времени.
3. **Работай только в этой папке.** Ничего не удаляй. Ничего не публикуй: никаких сайтов, проектов, игр,
   TikTok и конкурсов.
4. **Сохраняй всё.** Каждый результат клади в `out/<номер задания>/`: картинки — `.png` или `.jpg`, модели — `.glb`.
   - Если скачать файл не получается, запиши в `RESULTS.md` ссылку `result_url`. Claude Code скачает сам.
5. **Для каждой генерации записывай** в `RESULTS.md`: задание, шаг, модель, безлимит или нет, `job_id`, ссылку и
   имя файла.
6. **Лимит на объект:** не больше 6 картинок и не больше 2 моделей 3D. Если всё равно не выходит, запиши почему
   и иди дальше.
7. Безлимит пробного периода кончается **14 ноября 2026 в 06:46 UTC** (09:46 по Москве). Делай по порядку номеров:
   самое важное идёт первым.

## Как делать каждый объект (шаги A → B → C)

**A. Картинка-эскиз.**
1. Загрузи образцы из `refs/` (`media_upload` → PUT файла → `media_confirm`):
   - образец стиля — `refs/style_higgsfield_house_1.png`;
   - то, что сейчас стоит в игре, — файл `refs/now_…` из задания. Он задаёт форму и состав, но не стиль.
2. Сделай 3 картинки моделью для картинок с безлимитом и поддержкой образцов (`image_references`). Подойдут, например,
   Nano Banana Pro, GPT Image или FLUX — смотри по списку безлимита.
3. Промпт: СТИЛЬ (ниже) + описание из задания, на английском.
4. Если загрузить образцы не вышло, делай только по тексту.

**Выбери лучшую картинку** по списку:

- объект виден целиком, ничего не обрезано;
- фон чистый, светлый, без лишних предметов;
- вид 3/4 сверху;
- стиль как у образца: мягкие «пластилиновые» формы, крупная терракотовая черепица, тёплая охристая штукатурка,
  деревянные детали;
- много мелких деталей;
- нет людей, надписей и водяных знаков.

**B. 3D по лучшей картинке.**
1. Модель «картинка → 3D» с безлимитом. Подойдут, например, `tripo_h3_1_image_to_3d`, `tripo_p2_image_to_3d`,
   `hunyuan3d_v3_image_to_3d` или `meshy_v7_image_to_3d`.
2. Параметры: `face_limit` из задания (у Meshy — `target_polycount`), `texture_quality: "detailed"`, `pbr: true`.
3. Если «картинка → 3D» без безлимита, а `tripo_3d` (текст → 3D) с безлимитом — сделай `tripo_3d` с тем же текстом,
   `face_limit` из задания и `texture_quality: "detailed"`.

**C. Сохрани.** Модель — в `out/<номер>/<имя>.glb`, картинки — рядом. Запиши строку в `RESULTS.md`.

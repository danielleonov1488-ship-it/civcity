# CivCity

Уютный градостроитель в браузере: механики Town to City в римском облике Civ City Rome.
Город растёт сам, если жителям хватает воды, еды, храмов, товаров и красоты. Поражений нет.

## Как запустить

Дважды кликните по `index.html`, и игра откроется в браузере. Интернет не нужен: Three.js и шрифты лежат в папке `vendor`.
Прогресс сохраняется в браузере сам, каждые 15 секунд.

Через локальный сервер (для разработки):

```bash
python -m http.server 5180
```

и откройте http://localhost:5180

## Управление

- Левая кнопка: строить или выбрать здание. Дорогу тяните мышью.
- Правая кнопка: двигать карту и отменять инструмент. Колесо: масштаб. Средняя кнопка: вращение.
- WASD или стрелки: камера, Q/E: поворот, R: дорога, H: дом, X: снос, F: исследования, L: легион, пробел: пауза, 1/2/3: скорость.
- На телефоне: один палец двигает карту или строит, двумя пальцами масштаб и поворот.

## Устройство кода

Обычный HTML + JavaScript без сборки, скрипты подключаются по порядку в `index.html`.
3D рисует Three.js r158 (UMD-сборка, `vendor/three.min.js`). Шрифты Cormorant Garamond и Nunito — в `vendor/fonts` (лицензия OFL). Качество графики (низкое, среднее, высокое) и смена дня и ночи переключаются в настройках игры.

| Файл | Что внутри |
|---|---|
| `js/config.js` | Весь баланс: товары, постройки, уровни домов, исследования, походы |
| `js/util.js` | Шум для рельефа, числа, склонения |
| `js/world.js` | Бесконечная карта из участков 24×24, залежи, проверка стройки, оплата |
| `js/models.js` | 3D-модели всех зданий, деревьев и залежей, собранные кодом |
| `js/post.js` | Постобработка: тени в углах (AO), свечение, миниатюрное размытие, сглаживание |
| `js/atmos.js` | Небо, смена дня и ночи, тени облаков, ветер в листве, рябь воды, птицы, бабочки и светлячки |
| `js/engine.js` | Сцена, камера, земля и вода, здания и природа через инстансинг, жители-фигурки, частицы, подсказки стройки |
| `js/sim.js` | Игровой день: работники по классам, производство, потребление, налоги, исследования, торговля, задачи |
| `js/military.js` | Казармы, карта провинции, автобитва |
| `js/walkers.js` | Жители на улицах: маршруты, роли и одежда |
| `js/icons.js` | Рисованные значки товаров и советника, линейные иконки интерфейса, значки классов |
| `js/input.js` | Мышь, тач, клавиатура, призрак здания |
| `js/advisor.js` | Советник Марк, одноразовые подсказки, тревоги, журнал |
| `js/ui.js` | Верхняя панель, док стройки, карточка здания, окно «Империя», настройки, подсказки при наведении |
| `js/save.js` | Сохранение города и настроек в localStorage |
| `js/main.js` | Запуск и игровой цикл |

Чтобы покрутить баланс, меняйте числа в `js/config.js`. План развития лежит в [docs/DESIGN.md](docs/DESIGN.md).

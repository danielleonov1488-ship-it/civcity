# Решения владельца к плану от 14.10.2026 (вечер) — ОНИ ВАЖНЕЕ docs/PLAN_2026-10-14_tech.md

Где этот файл расходится с тех. планом, делаем как здесь.

## Д1. Ранг — как в Town to City, бесплатно, по кнопке (заменяет STAGE 1b п.1 «Paid rank ceremony»)
- Платы за новый ранг НЕТ (церемонию за деньги придумали мы — владелец её отверг).
- У каждого ранга, начиная с «Хутор», есть условия: жители, счастье И постройки этого этапа
  (2–4 пункта: например «фруктовая лавка», «скрипторий», «три разные лавки еды», «фонтан», «склад»,
  «5 домов с 2-м этажом», «школа», «храм»…). Постройки в условиях — только те, что можно открыть
  исследованиями ТЕКУЩЕГО ранга или раньше (иначе тупик). Данные — в Defs.LEVELS (новое поле, например "need").
- Когда все условия выполнены, город НЕ повышается сам: светится плашка уровня и появляется кнопка
  «Перейти на новый уровень» (в подсказке уровня / карточке станции; на видном месте, как зелёная кнопка в TtC).
  Нажатие → level += 1 → level_up (ролик rank_cine играет по нажатию) → открываются новые исследования.
- Список условий виден заранее: в подсказке уровня — чек-лист с галочками (выполнено / нет, сколько из скольких).
- Советник один раз объясняет: «Город готов к новому уровню — нажмите…». Без всплывашек (правило владельца).
- Это и для «Хутора» (обучение после шага «исследования» — проверить, что не ломается; при необходимости
  первый ранг подсказывает советник со стрелкой на кнопку).
- Просьбы горожан hamlet / village (сейчас — «собрать N жителей») привести в согласие с новыми условиями
  (например «Станьте хутором» с прогрессом по условиям), чтобы не было противоречий.
- Живое сохранение владельца: текущий уровень не понижается.

## Д2. Пределы по уровню для школ, библиотек, академий — как у скрипториев (жёстко)
- Механика та же, что у скрипториев: максимум на уровень, с ростом города можно ещё +2–3.
- school [0, 0, 2, 4, 5, 6, 7, 8]; library [0, 0, 0, 0, 2, 3, 4, 5]; academy [0, 0, 0, 0, 0, 0, 1, 2];
  scriptorium как есть [1, 2, 3, 4, 5, 6, 8, 10].
- Сверх предела в старых городах (у владельца много школ): не работают (только первые build_max по id),
  в карточке — «сверх предела уровня — не работает». Не сносить и не удалять.

## Д3. Круги охвата — убрать совсем
- Никаких колец радиуса у лавок (ни при постройке, ни при выборе). Охват показываем только подсветкой домов:
  синим — дома, которые уже снабжает такая же лавка; зелёным — которым новая лавка правда что-то даст;
  подпись «новых домов: 6, уже с гончарной: 3».
- Кнопка «показать радиусы всех лавок» — убрать; вместо неё «Обзор» (счастье каждого дома / одна потребность) — как в плане 2.2.

## Д4. Этаж
- Инструмент «Этаж» (U) — как в плане. Кнопки «надстроить все готовые разом» НЕ делать.

## Д5. Легион — раньше
- Легион (первая область «Лес разбойников») открывается раньше: на ранге «Посёлок» (индекс 3), а не «Городок».
- Следующие области тоже раньше, без пустоты после леса: REGIONS ranks примерно [3, 4, 5, 5, 6, 6, 7, 7]
  (исследование «Легион» и Казармы — доступны к этому рангу; проверить цепочку).
- Плюс всё из этапа 3 плана: масло с первого дня, учебный первый бой, «Авто» только для пройденных,
  угрозы, звёзды, обучение в 4 шага.

## Д6. Деньги
- Как в TtC: сначала денег немного не хватает, потом начинают копиться — то, что в плане 1a (налоги, жалованье,
  содержание). Траты: праздники «Игры в честь богов», земля (новые игры), чудеса, этажи. Церемонии за деньги — нет.
